Entertainment

エンターテインメント事業

VTuber の「やりたい」を、
カタチにする。

所属していただく必要はありません。活動の外側にある仕事を引き受け、配信者が配信に集中できる状態をつくります。あわせて、ファンと出会う場としてのイベントと、当社が主催する自社 IP 番組を手がけます。

サービス内容

Services

ひとつだけでも、組み合わせても構いません。契約は項目ごとに結び、途中で増やしたり減らしたりできます。

01ACTIVITY SUPPORT
01SUPPORT

VTuber 活動サポート

配信の外側の仕事を、引き受けます。

企業案件の調整と実施管理、配信環境の整備、サムネイルや切り抜き動画の制作、投稿計画の設計、受注生産のグッズ企画。担当者がつき、月に一度は活動の振り返りをします。

  • 所属不要・非専属。他の活動や他社との契約を妨げません
  • 必要な項目だけを選んで契約し、追加や解約はいつでも相談できます
  • 料金と条件は契約の前に書面で開示します
02EVENT
02EVENT

VTuber イベント

ファンと出会う場を、つくります。

配信イベント、オンラインのファンミーティング、複数の VTuber によるコラボ企画、リアル会場でのビューイングまで。企画、出演者の調整、当日の運営、グッズ販売を一括で手がけます。

  • オンラインとリアルの両方に対応します
  • 出演は非専属のまま。所属の有無を問いません
  • チケット・グッズの収益配分は事前に取り決めます
03ORIGINAL IP
03ORIGINAL IP

自社 IP 番組

当社が主催する番組に、出演枠を。

ゲーム大会やバラエティ企画など、当社が企画・主催する番組を制作します。出演枠は所属を問わずオープンに設け、企業の協賛枠を当社が営業します。配信者には出演と露出の機会を、企業には届く接点を提供します。

  • 番組の企画・制作・配信・アーカイブ運用まで一括
  • 出演者の募集は公開し、条件を明示します
  • 協賛枠の内容と価格は企画ごとに個別にご案内します
04EVENT PRODUCTION
04PRODUCTION

イベント企画・運営

企業の場に、VTuber の演出を。

周年イベント、新商品の発表会、社内イベント、地域のお祭り。VTuber を起用した企画と演出、キャスティング、配信の設計、当日の運営までを引き受けます。

  • 企画から当日運営まで一括で対応します
  • 契約と請求の窓口は当社。配信者と直接やり取りする必要はありません
  • PR 表記や権利の取り扱いも当社が整理します
対象の方

For Whom

活動歴やファンの数によって、困りごとは違います。3 つの段階に分けて、それぞれに合う支援を用意しています。

A

一定のファンがいる方

活動は軌道に乗っているが、配信の外側の仕事が増えてきた方。

  • 税務・法務の相談
  • 案件の獲得と実施管理
  • 配信・動画作成の支援
  • グッズ制作
B

自分で走れる方

配信は続けられているが、次の一手に迷っている方。

  • 案件の獲得
  • 構成の考案
  • 配信・動画作成の支援
  • 税務・法務の相談
C

これから始める方

やりたい気持ちはあるが、何から手を付けるべきか分からない方。

  • キャラクター・機材の相談
  • 構成の考案
  • 配信環境の整備
  • 始めてからの伴走
